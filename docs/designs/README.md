# Clare's Life Celebrations Print Design Mockups

Editable HTML source and exported PDF mockups for printed materials.

Files:

- `business-card.html` / `business-card.pdf` - two-page 85mm x 55mm business card, front and back.
- `a5-business-card-style.html` / `a5-business-card-style.pdf` - two-page A5 landscape design using the business card template style.
- `wedding-a4-flyer.html` / `wedding-a4-flyer.pdf` - A4 wedding ceremony flyer.
- `funeral-director-a5-flyer.html` / `funeral-director-a5-flyer.pdf` - A5 funeral director flyer.
- `shared-print.css` - shared print styling for all mockups.

The HTML files reference the existing website assets in `src/main/resources/static/images`.
